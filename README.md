# Panel de usuarios · Clinical Hub

La plataforma que usan los médicos: resúmenes de guías, algoritmos y figuras,
herramientas interactivas, videos y Clinical News.

Es un proyecto aparte del panel de administradores: otro repositorio, otro
frente y su propia base de datos.

## Qué hay aquí

- `estilos/clinical-hub.css`: el manual de marca (colores, letra, radios, sombras y piezas).
- `public/`: el ícono de la marca y los íconos de línea.

## Lo que viene

1. Crear el proyecto con Next.js, React y TypeScript (hace falta Node).
2. Pasar el manual a piezas: botón, chip, etiqueta, campo, tarjeta.
3. El marco: menú lateral con Nuevo, Herramientas interactivas, Algoritmos y
   figuras, Resúmenes de guías, Videos y Clinical News.
4. La primera pantalla: la biblioteca de guías.
